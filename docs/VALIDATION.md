## 真实服务器连接与清理

老板提供的 HTTPS WebDAV 端点，使用生产 WebDAV 模块 PROPFIND Depth 0 返回 401；使用独立 curl Basic 认证再次 PROPFIND，同样返回 401。服务器尚未创建测试目录或设备文件，真实 PUT/GET 往返待有效应用连接信息后补验。

临时认证文件均已删除；真实账号与密码从源码、文档、测试夹具、安装包及本轮交付文件中排除。真实请求仅用于提供商指定端点，浏览器测试始终使用虚构连接。

## 手动验收

1. 在原固定目录覆盖 0.0.5 文件，重新加载同一扩展并刷新阅读页，检查原词本数量与学习材料。
