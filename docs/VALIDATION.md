## 验证边界

浏览器安全策略拒绝 `chrome://extensions/`，实际加载 MV3 扩展需老板手动完成；本轮 HTTP 测试页验证界面和生产后台逻辑，实际 Chrome storage、后台休眠、升级与真实网站兼容性须在扩展加载后验收。加括号翻译需要可恢复的行内 span，会为译文增加排版空间；动态框架网站的实际表现仍须实页确认。

0.1.0 已验证官方 deepseek-flash API 的真实生产提示词响应和有道公开发音：trail / resilient 返回有效完整 JSON；发音返回有效 MPEG 音频。Node 默认 DeepSeek 网络路径曾有 522/超时，系统 curl 路径成功。本轮复用相同请求函数，新增缓存与存储测试使用模拟结果。本轮没有新增付费模型请求。实际扩展网络和播放需加载后验收。

词库中文义为简短通用义，AI 保存的是首次查询语境对应的义。同词复用会保持该义项；多义项或手动刷新属于后续功能。顶层普通 HTML 是当前支持范围，词形变化分别维护；iframe、网页 Shadow DOM、PDF、代码区及编辑区各有独立支持需求。

## 手动验收

1. 从原目录更新加载本次 `extension/`，或按 README 加载 `dist/lexitrail-0.0.3/`。更新已有扩展时保留原扩展身份，现有 schema 1 词本会自动补上中文义。
2. 生词后默认显示括号中文义；切至学习中显示橙色虚线，切至已掌握恢复原文。设置开关关闭后标注消失，选词查词继续可用。
3. 查一个生词，暂时保持生词状态：词本显示离线中文义，已保存 AI 材料栏目保持空白。同一后台存活期间重复查询该词应复用临时结果。
4. 将词加入学习中，展开词本中的“已保存的释义与例句”；检查中文义、英文定义、英文例句、例句中文、首次查询语境与日期。原文收藏语境另列。
5. 选择词库外英文词，分别在结果返回前、结果返回后加入学习中，确认材料均保存。打开卡片后等待后台休眠，再加入学习中，确认卡片结果仍保存。
6. 重启浏览器，或清除 Key；已保存的词仍可查阅原来的释义与例句。切回生词本后材料继续保留。
7. 在两个网页和词本页确认状态同步；检查真实网站排版、文本选取和复制，以及字典音频/系统发音。

数据字段与未来卡片/同步接口的基础见 [DATA_MODEL.md](DATA_MODEL.md)。浏览器夹具：`node tests/preview-server.js`；访问 `http://127.0.0.1:8781/options.html` 和 `/article.html`。夹具状态只存在开发服务器进程中，示例页标明模拟 LLM，发布包包含生产文件及文档。
